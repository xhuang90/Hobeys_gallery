## 分支说明

| 分支 | 用途 | 说明 |
|------|------|------|
| `main` | 生产分支 | 稳定版本，部署前从 develop 合并 |
| `develop` | 开发分支 | **日常开发在这里**，改代码、加功能都在这个分支 |
| `gh-pages` | 部署分支 | 仅含构建产物（index.html + assets + images），由部署脚本自动维护 |
| `productive` | Vercel 备用 | 历史遗留，不再使用 |

### 日常开发流程

```bash
# 1. 切换到开发分支
git checkout develop

# 2. 启动开发服务器
npm run dev

# 3. 修改代码...
# 4. 提交
git add -A && git commit -m "描述你的改动"
git push origin develop

# 5. 准备好发布时，合并到 main 并部署
git checkout main
git merge develop
git push origin main
bash deploy.sh github
git checkout develop   # 回到开发分支
```

## 本地预览

### 首次启动

```bash
cd sec_brains/Hobeys_gallery
npm install          # 安装依赖（仅首次）
npm run dev          # 启动开发服务器
```

启动成功后访问 `http://localhost:5173`

### 日常启动

```bash
cd sec_brains/Hobeys_gallery
npm run dev
```

### 停止服务

终端按 `Ctrl + C`

## 编辑藏品

直接编辑对应的 Markdown 文件，刷新浏览器即可看到效果（开发模式自动热更新）。

### 添加封面图

1. 把图片放到 `collections/images/` 目录
2. 在 Markdown 里加 `cover: images/xxx.jpg`

## 数据结构速查

### 通用字段

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 标题（必填） |
| status | string | 状态（必填） |
| rating | number | 1-5 星 |
| cover | string | 封面图路径 |
| tags | array | 标签列表 |
| added | date | 入库日期 |

### 状态值

| 类型 | 可选值 |
|------|--------|
| 乐高 | built / unbuilt / wishlist |
| 唱片 | owned / wishlist |
| 书籍 | read / reading / unread / wishlist |
| 电影 | watched / wishlist |
