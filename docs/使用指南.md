## 本地预览

在本地启动开发服务器，实时查看网站效果。

### 首次启动

```bash
# 1. 进入项目目录
cd /path/to/myvault

# 2. 安装依赖（仅首次）
npm install

# 3. 构建数据 + 启动服务器
npm run dev
```

启动成功后，访问 `http://localhost:5173`

### 日常启动

```bash
cd /path/to/myvault
npm run dev
```

### 停止服务

在终端按 `Ctrl + C`

## 编辑藏品

### 修改数据

直接编辑对应的 Markdown 文件：

```bash
# 用你喜欢的编辑器
vim collections/lego/75313-ucs-at-at.md
code collections/lego/75313-ucs-at-at.md  # VS Code
```

### 修改状态

比如乐高从"未拼"变成"已拼"：

```markdown
# 修改前
status: unbuilt

# 修改后
status: built
built_date: 2026-08-03
```

### 添加封面图

1. 把图片放到 `collections/images/` 目录
2. 在 Markdown 里加一行：

```markdown
cover: images/lego-75313.jpg
```

### 删除藏品

```bash
rm collections/lego/75313-ucs-at-at.md
```

## 部署上线

### 自动部署（推荐）

已配置 Cloudflare Pages，每次推送到 GitHub 会自动部署：

```bash
# 1. 提交改动
git add .
git commit -m "✨ 新增千年隼"

# 2. 推送
git push

# 3. 等待 1-2 分钟，网站自动更新
```

### 手动构建

```bash
# 构建生产版本
npm run build

# 输出目录：dist/
# 可以上传到任何静态托管服务
```

## 常见问题

### Q: 网站打不开？

```bash
# 重启开发服务器
npm run dev
```

### Q: 改动没生效？

```bash
# 重新构建数据
npm run build

# 或者
npm run dev  # 开发模式会自动监听
```

### Q: 图片显示不出来？

1. 确认图片在 `collections/images/` 目录
2. 确认 Markdown 里的路径正确：`cover: images/xxx.jpg`
3. 重新运行 `npm run build`

### Q: 想改网站样式？

告诉我你想要什么效果，我来改 CSS 和 Vue 组件。

### Q: 数据备份？

所有数据都在 `collections/` 目录，定期备份这个文件夹即可：

```bash
tar -czf myvault-backup-20260803.tar.gz collections/
```
