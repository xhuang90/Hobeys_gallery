# 部署指南

## 分支说明

| 分支 | 用途 |
|------|------|
| `main` | 生产分支，稳定版本 |
| `develop` | 开发分支，日常开发用 |
| `productive` | Vercel 部署分支（备用） |
| `gh-pages` | GitHub Pages 部署分支（仅含构建产物） |

## GitHub Pages 部署（推荐，国内可访问）

### 一键部署

```bash
bash deploy.sh github
```

### 部署原理

1. 本地执行 `npm run build` 生成 `dist/` 目录
2. 将 `dist/` 内容复制到根目录（`index.html`、`assets/`、`images/`、`data.json`）
3. 推送到 `gh-pages` 分支
4. GitHub 自动部署到 https://xhuang90.github.io/Hobeys_gallery/

### 关键配置

- `vite.config.js` 中 `base: '/Hobeys_gallery/'` — 确保资源路径正确
- `src/useEntries.js` 中 `fetch(import.meta.env.BASE_URL + 'data.json')` — 确保数据路径正确

## Vercel 部署（备用，国外访问快）

```bash
bash deploy.sh vercel
```

部署到 https://hobeys-gallery.vercel.app

## 日常开发流程

```bash
# 1. 切换到开发分支
git checkout develop

# 2. 启动开发服务器
npm run dev

# 3. 修改代码后提交
git add -A && git commit -m "描述你的改动"

# 4. 合并到 main
git checkout main
git merge develop
git push origin main

# 5. 部署
bash deploy.sh github
```
